IANS OneDrive Analyzer V1.2 – oppsett

Sikkerhet: V1 ber kun om delegert Microsoft Graph-tillatelse Files.Read. Den kan lese den innloggede brukerens OneDrive, men kan ikke flytte, skrive eller slette filer. Ingen client secret skal opprettes eller legges i HTML.

1. Kjør siden via lokal webserver

Ikke åpne index.html direkte som file://. Åpne Terminal i mappen og kjør:

python3 -m http.server 8080

Åpne deretter http://localhost:8080/.

2. Opprett appregistrering i Microsoft Entra

  1. Gå til Microsoft Entra admin center → App registrations → New registration.
  2. Gi appen navn, for eksempel IANS OneDrive Analyzer.
  3. Velg kontotype som inkluderer kontoene du vil teste. For både jobb/skole og private Microsoft-kontoer, velg alternativet som inkluderer personal Microsoft accounts.
  4. Opprett appen.
  5. Kopier Application (client) ID.

3. Legg inn Redirect URI som SPA

  1. I appregistreringen: Authentication → Add a platform.
  2. Velg Single-page application.
  3. Legg inn http://localhost:8080/ (eller nøyaktig adressen dashboardet viser).
  4. Lagre.

4. Microsoft Graph permissions

I API permissions → Add a permission → Microsoft Graph → Delegated permissions:

  • Files.Read

Det er alt V1 trenger for OneDrive-kartlegging. Ikke legg inn Files.ReadWrite.

5. Start

  1. Lim Client ID inn på oppsettsiden.
  2. Klikk Koble til OneDrive.
  3. Godkjenn Files.Read.
  4. Klikk Start full kartlegging.

Hva V1 kartlegger

  • OneDrive-kvote / brukt plass
  • alle mapper og filer som Graph returnerer for den innloggede OneDrive
  • summerte filstørrelser
  • filkategorier
  • største mapper og filer
  • photo.takenDateTime der Microsoft Graph eksponerer det
  • opprettet dato som fallback
  • mulige duplikater basert på samme filnavn + størrelse
  • JSON-eksport av kartleggingen

Viktig ved svært store OneDrive-kontoer

Kartleggingen henter metadata side for side. Den laster ikke ned selve filinnholdet. En konto med svært mange små filer kan likevel kreve mange Microsoft Graph-kall. V1 håndterer paginering og vanlige 429/503/504-throttling-svar med retry.
