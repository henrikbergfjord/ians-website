Vanlig bruk av verktøyene

Website Studio behandler prosjekttekst og bilder i nettleseren. Fil- og prosjekteksport blir filer du selv velger å lagre. Lokal lagring i nettleseren skjer når du velger det. Slett nettleserlagringen eller bruk verktøyets slettevalg for å fjerne en lagret kopi.

Money Planner regner budsjettet i nettleseren. Selve standardbudsjettet sendes ikke til en IANS-budsjettdatabase. File Commander bruker lokale filer du selv har valgt; filhandlinger og valgfri KI er ulike funksjoner.

OneDrive-kartlegging bruker Microsoft-innlogging og Microsoft Graph. Kartlegging, lagrede skanninger og lokale eksporter kan inneholde filnavn og annen fortrolig metadata. Action Mode krever ekstra tilgang. Del ikke skannefiler uten å kontrollere innholdet.

Kontakt og tilgangsforespørsler

Kontakt- og tilgangsskjema bruker navn, e-post, emne, melding og eventuelle opplysninger om virksomhet, sameie og rolle. Opplysningene brukes til å svare, vurdere tilgang og følge opp den forespørselen du sender. Ikke skriv inn helseopplysninger, passord, fødselsnummer eller opplysninger om andre som ikke trengs.

Forespørsler lagres i Microsoft Azure med tidspunkt og behandlingsstatus. Enkelte forespørsler kan også varsles på e-post gjennom Microsoft Azure Communication Services når varsling er konfigurert. Tilgang kan kreve Microsoft-innlogging og individuell godkjenning.

Det er ikke implementert en fast automatisk slettefrist for vanlige kontakt- og tilgangsforespørsler. Ta kontakt for innsyn, retting eller sletting. Aktive tilgangsopplysninger kan være nødvendige så lenge tilgangen skal fungere; avsluttede saker må vurderes og ryddes av den ansvarlige.

Registrering av sameier

Registreringsskjemaet ber om sameiets opplysninger, kontaktperson og eventuelle styremedlemmer. Du kan velge profilbilde og beboerliste. Innsending krever innlogging og bekreftelse på fullmakt.

Registreringen lagres som en forespørsel i Azure Table Storage. Vedlegg lagres i et eget onboarding-område i Azure Blob Storage, og blir ikke publisert som del av en offentlig booking. Ikke legg ved mer informasjon enn nødvendig. Lagringstid og videre bruk må avklares med sameiet før en slik liste tas i ordinær drift.

Valgfri KI-behandling

En KI-handling sender de opplysningene som er beskrevet ved knappen. IANS bruker Azure som backend og OpenAI API som modellleverandør der KI er aktivert. Det er ikke det samme som lokal beregning.

  • Money Planner: økonomiske nøkkeltall, husholdnings- og boligforhold og mål. Navnefeltet følger ikke med analyseforespørselen.
  • File Commander: fil-/mappenavn, type, størrelse, dato, panel og spørsmålet ditt. Ikke selve filinnholdet.
  • Dinner Planner: matønsker, antall personer, budsjett, varer hjemme og eventuelt valgt bilde ved KI-planlegging. Reserveplan uten aktiv KI analyserer ikke bildet.
  • Annonsehjelp: produkttekst, tilstand og bilder du velger for annonsen.

Navn kan likevel stå i filnavn, bilder eller fritekst. Kontroller dette før du sender. Ikke bruk identifiserbare eller sensitive data for å teste verktøyene.

OpenAI beskriver egne regler for API-data og sikkerhetslogger. IANS lover ikke null lagring hos leverandøren og har ikke dokumentert en særskilt Zero Data Retention-avtale. Leverandørbehandling kan skje utenfor Norge. Les OpenAIs offisielle datakontroller før bruk med opplysninger du ikke ønsker å dele. Teksten er kontrollert 16. oktober 2026.

En personvernbeskrivelse erstatter ikke en kontroll av faktisk drift. Sameiet må følge opp databehandlerforhold og dokumenterte sletterutiner.

Besøksstatistikk og teknisk drift

IANS sin egen sidevisningsteller sender sidestien uten søkestreng og fragment. Telleren lagrer antall per side og dag samt første og siste registreringstidspunkt. Den bruker ikke en egen bruker-ID, informasjonskapsel eller fingerprint for denne tellingen.

Microsoft og andre tjenester kan i tillegg behandle tekniske tilkoblingsopplysninger ved levering, feilsøking og sikkerhet. Dette er ikke en garanti for at ingen tekniske logger finnes. Innebygde eksterne tjenester, som Google Calendar og eksterne oppslag, har egne vilkår. DNS-sjekk sender domenet og valgt posttype til Google Public DNS (dns.google). Åpne bare innhold du er komfortabel med å hente fra disse leverandørene.
