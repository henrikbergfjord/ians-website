PERSONVERN OG VILKÅR

Trygg og tydelig bruk

Henrik Academy er en privat og tilgangsstyrt læringsportal utviklet og administrert av Henrik Bergfjord. Denne siden forklarer hvordan personopplysninger behandles og hvilke vilkår som gjelder for bruk av Academy.

Personopplysninger

Når du sender en tilgangs- eller kontaktforespørsel kan navn, e-postadresse, virksomhet, rolle/fagområde, melding, tidspunkt og behandlingsstatus lagres. Opplysningene brukes for å vurdere forespørselen, administrere tilgang, følge opp henvendelser og ivareta sikkerhet og historikk.

Opplysningene er kun ment å være tilgjengelige for den som administrerer Henrik Academy og tekniske tjenester som er nødvendige for drift. Det selges ikke personopplysninger.

Innsyn, retting og sletting

Du kan be om innsyn i hvilke opplysninger som er lagret om deg, be om retting eller be om sletting når opplysningene ikke lenger er nødvendige for formålet. Kontakt Henrik via kontaktsiden.

Tilgangsdata og historikk kan beholdes så lenge det er nødvendig for å administrere aktiv eller tidligere tilgang, håndtere sikkerhet og dokumentere beslutninger.

Innlogging og tilgang

Innlogging skjer via Microsoft Entra ID. Tilgang er personlig, knyttet til godkjent konto og kan tilbakekalles. Henrik Academy lagrer ikke Microsoft-passordet ditt.

Opphavsrett og kilder

Egne tekster, struktur, design, forklaringer og bearbeidet innhold i Henrik Academy er laget som del av det private læringsprosjektet og skal ikke kopieres, republiseres eller distribueres uten tillatelse. Eksterne tekster, dokumenter, navn, logoer og annet kildemateriale tilhører sine respektive rettighetshavere.

Academy er ikke en offisiell tjeneste fra Statnett, NVE, Regjeringen, Stortinget eller andre eksterne virksomheter. Se kilder og faglig grunnlag.

Kontakt

Spørsmål om personvern, tilgang eller bruk kan sendes via Kontakt Henrik Bergfjord.
